## v1.8.0 - 2026-11-11
### Changed
* v2beta1: all v2beta1 service operations now take variadic ScopeOption values instead of positional orgID, projectID, instanceID and databaseID string parameters; backup, user and invite identifiers are added as scope leaves. The scope is supplied per call with WithOrg, WithProject, WithInstance, WithDatabase, WithBackup, WithUser or WithInvite, or once at client construction with WithDefaultOrg, WithDefaultProject and WithDefaultInstance, where a per-call option overrides the matching default and an unset field inherits it. Operations that carry a request body take that body before the trailing scope options.
* v2beta1: the default User-Agent header sent by the v2beta1 client now carries a /v2beta1/ segment (e.g. aura-go-sdk/v2beta1/<version>) so server-side telemetry can distinguish v2beta1 requests from stable-v1 traffic when a consumer uses both sub-modules.
